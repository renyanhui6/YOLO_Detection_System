5. 依赖版本冲突分析
========================================

注意事项:
1. ultralytics版本差异:
   - server_python: 8.0.196
   - yolo_server: 8.3.0
   建议统一使用较新版本 8.3.0

2. torch版本要求:
   - server_python: 固定版本 2.0.1
   - yolo_server: >=2.0.0
   - ultralytics: >=1.8.0
   建议使用 torch>=2.0.1

3. Flask版本:
   - 项目使用: 2.3.3
   - ultralytics建议: >=3.0.1
   当前版本可正常工作，升级需谨慎测试

========================================
6. 安装建议
========================================

前端安装:
npm install

后端主服务器安装:
cd server_python
pip install -r requirements.txt

YOLO服务器安装:
cd yolo_server
pip install -r requirements.txt

完整Ultralytics安装(如需开发):
cd ultralytics-main
pip install -e .
